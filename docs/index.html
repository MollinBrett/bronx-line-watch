How it works

We check the MTA's public service alerts every minute. When a new disruption starts on a Bronx line, an AI model (Claude, by Anthropic) rewrites the official alert into a short, plain-language text in English and Spanish, and we send it to subscribers. We text about real-time disruptions only, not ads, and never anything unrelated to subway service.

Who runs this

Bronx Line Watch is a free, non-commercial community project run by volunteers. It is not affiliated with or endorsed by the MTA. For official service information, see new.mta.info. The code is open source on GitHub.
